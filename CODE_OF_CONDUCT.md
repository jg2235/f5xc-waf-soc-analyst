# Code of Conduct

## Our standard

This project is maintained in a professional engineering context. Contributors are
expected to be respectful, constructive, and direct. Disagree with the technical
argument, not the person making it.

Unacceptable behaviour includes harassment, personal attacks, discriminatory
language, and publishing others' private information.

## Security-tooling specifics

This repository builds offensive-adjacent security analysis tooling. Two rules
follow from that:

- **Do not post live customer, tenant, or personal data** in issues, pull requests,
  or discussions — including source IP addresses, hostnames, support IDs, and
  tenant identifiers. Redact before sharing.
- **Do not use this tooling against infrastructure you are not authorised to
  assess.** Contributions that add unauthenticated scanning, attack execution, or
  detection-evasion capability will be declined.

## Enforcement

Report concerns to `jgranieri22@outlook.com`. Maintainers may remove content, and may
restrict participation for behaviour they judge inappropriate.
